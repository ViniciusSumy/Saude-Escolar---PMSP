# Saúde Escolar: ficha integrada Saúde–Educação (protótipo)

Projeto Integrador de Laboratório de Programação, Universidade Santo Amaro (UNISA), 2026.

Protótipo web, em HTML, CSS e JavaScript puros, de uma ficha compartilhada entre as redes de Saúde e de Educação. Cada perfil de acesso vê e edita apenas o que é da sua função.

## Demonstração

- Online (GitHub Pages): `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
- Local: abra o arquivo `index.html` no navegador. Não há instalação nem servidor.

## Contas de demonstração (senha: `demo123`)

| Usuário | Perfil | Acessa |
|---|---|---|
| `psicologa` | Psicóloga (UBS) | Neurodiversidade e relatórios da escola |
| `enfermagem` | Enfermagem (UBS) | Alergias e condições, vacinas e laudos de dieta |
| `gestao` | Gestão escolar | Seções pedagógicas e contato; também o EOL Funcionários (RH) |
| `secretaria` | Secretaria escolar | Igual à gestão, sem o EOL Funcionários |

Códigos EOL de demonstração: `1000001` a `1000008`.

## Aviso

Todos os dados são **fictícios**. O login é simulado e não há integração com o EOL, com o SIGPAE nem com sistemas de saúde. Em produção seria necessário back-end, banco de dados e autenticação institucional.
